# 🎮 Block Blast Web Game

Game puzzle balok bergaya Block Blast yang responsif, modern, dan ramah mata. Dibuat dengan HTML5, CSS3, dan Vanilla JavaScript murni.

## ✨ Fitur Utama
- **Gameplay Menarik & Halus**: Papan 8x8 dengan drag-and-drop intuitif, deteksi tabrakan presisi, kombo beruntun, dan efek ledakan balok yang memuaskan.
- **6 Tema Estetik & Ramah Mata**:
  - Warm Ivory & Crimson (Klasik)
  - Midnight Slate (Mode Malam)
  - Pastel Macaron
  - Zen Bamboo & Teak Wood
  - Nordic Frost
  - Obsidian Gold
- **Fitur Lengkap**:
  - 🏆 **Papan Peringkat (Leaderboard)**: Peringkat global & riwayat permainan.
  - 🎡 **Lucky Spin**: Putar roda harian untuk memenangkan koin & booster.
  - 📅 **Hadiah Harian**: Login streak harian & misi tantangan berhadiah koin.
  - 💣 **Booster Perkakas**: Bom (ledakkan 3x3), Palu (hancurkan 1 balok), dan Acak Balok (refresh tray).
  - 💖 **Dukungan / Donasi QRIS**: Terintegrasi modal scan QRIS.
  - 📱 **Mobile-First & Responsif**: Tampilan bersih tanpa scrollbar, optimal di smartphone maupun desktop.

## 🚀 Cara Menjalankan

### Opsi 1: Langsung di Browser (GitHub Pages / Standalone)
Buka file `index.html` langsung di browser favorit Anda, atau aktifkan **GitHub Pages** di repositori ini.

### Opsi 2: Menggunakan Server Lokal (Node.js)
```bash
node server.js
```
Akses di browser: `http://localhost:3000`
